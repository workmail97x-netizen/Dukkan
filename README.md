# مكتبة المصطفى — نظام إدارة المكتبة

نسخة مخصصة من Dukkan لإدارة **مكتبة المصطفى**: الكتب، الملازم، القرطاسية، الدفاتر، الأقلام والمستلزمات المدرسية. واجهة عربية RTL، قاعدة بيانات محلية، وتشغيل دون إنترنت.

> هذه النسخة ما زالت قيد التطوير والاختبار. لا تستخدمها كمصدر وحيد لحسابات المكتبة أو مخزونها قبل اختبارها على بيانات تجريبية والتحقق من النسخ الاحتياطي.

## الهوية والإعدادات

- الاسم الظاهر: مكتبة المصطفى.
- العملة: الدينار العراقي (IQD / د.ع)، مع عرض المبالغ بالدينار الصحيح دون كسور.
- واجهة عربية من اليمين إلى اليسار.
- تصميم محدث بألوان أخضر مكتبي ولمسات ذهبية، قابل لتغيير اللون والشعار.
- تطبيق Windows مبني باستخدام Tauri 2؛ لا يحتاج المستخدم النهائي إلى Node.js.

## ميزات النظام الأساسية

- نقطة بيع، فواتير نقدية وآجلة، طرق دفع متعددة.
- إدارة الكتب والملازم والقرطاسية والتصنيفات والموردين والعملاء.
- إدارة المخزون والمشتريات والمرتجعات والمصروفات والتقارير.
- باركود USB وباركودات متعددة للصنف، مع دعم قيد التطوير لربط باركودات الدفعات.
- دفعات توريد منفصلة وتكلفة شراء تاريخية، مع أسعار بيع على مستوى الدفعة قيد الاختبار.
- أدوار المستخدمين: مدير النظام، مدير المخزن، والبائع/الكاشير.
- نسخ احتياطي واستعادة محليان.
- العمل دون إنترنت بعد تثبيت التطبيق.

## البناء والتشغيل للمطورين

المتطلبات: Node.js 22، Rust toolchain، ومتطلبات بناء Tauri الخاصة بنظام Windows.

```bash
npm ci
npm run dev
npm run build
npm test
npm run tauri build
```

ملف بناء Windows يُنتج بواسطة GitHub Actions على فرع `feature/library-batch-barcodes`. راجع صفحة [Actions](https://github.com/workmail97x-netizen/Dukkan/actions) لمعرفة نتائج آخر بناء وتنزيل الـ artifact.

## بيانات المكتبة

في التشغيل الأول، يظهر اسم «مكتبة المصطفى» والتصنيفات الأساسية للمكتبة كقيم ابتدائية. أكمل بيانات الهاتف والعنوان، وارفع شعار المكتبة من الإعدادات إن توفر. احتفظ بنسخ احتياطية خارج الجهاز بصورة منتظمة.
